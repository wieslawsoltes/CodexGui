# Roadmap

CodexGui is in an active parity-building phase.

## Already landed

- native Avalonia shell and desktop information architecture
- local and remote transport support
- thread browsing and detail inspection
- turn authoring, thread start/resume, and interruption flows
- pending approval and tool-input surfaces
- item-specific rendering for commands, diffs, plans, reasoning, and tool calls

## Remaining gaps called out in the repository

- review mode workflows
- thread rollback and forking polish
- broader auth management, including ChatGPT token refresh handling
- deeper app and skill administration surfaces
- parity for remaining server-request types and higher-volume streaming polish
